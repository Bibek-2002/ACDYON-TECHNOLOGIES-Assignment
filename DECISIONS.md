ApplyWise - Decisions
1. Strategy Choice

I chose to build the website with HTML, CSS and JavaScript because the main purpose of the project is to create a simple marketing site for a desktop device with basic interactivity.

I tried to keep the design simple, without additional sections and functionality, focusing on the main product concept. Main page consists of hero section, product analysis preview, how it works section, resume insights, features and a call to action at the end.

A dark-themed website with blue, purple and pink accents gives it a modern and technology oriented look.

2. Time Limitation and Its Consequences

Because of the limited time for developing the website, I started with the main user experience.

I concentrated on such things as page structure, visual design, product preview, navigation, call-to-action buttons and responsive design.

In this version of the website I did not try to develop the backend, authenticate users and add job analysis functionality. The goal was to present the main product idea using frontend and make it functional.

I separated the responsive styles into another CSS file to keep the desktop version simple and easy to manage.

3. AI Usage and Its Verification

AI was used only as an auxiliary tool for final stage of the project development.

I firstly created the design direction and structure of the website myself. Then I used AI to check the design and suggest places for small animations and interactions which could be useful in user experience.

Also, AI helped me in making final check for the website in terms of alignment, spacing and consistency of visuals. The suggestions were verified manually and only those changes were made that fit the design of the website.

At the last step I checked the website manually in browser on both desktop and mobile viewport. Also I verified the layout and spacing to make sure that all the content is correctly aligned.
